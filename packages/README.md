# PayStreamer Packages (`/packages`)

This directory contains the shared internal libraries that are consumed by the applications in the `/apps` directory. PayStreamer utilizes pnpm workspaces to manage internal dependencies cleanly.

## Directory Map

* 🔗 **[SDK (`/packages/sdk`)](./sdk/README.md)**: The foundational TypeScript SDK for the entire ecosystem. It abstracts all interactions with the Sui blockchain and provides a centralized source of truth for deployment configurations.
