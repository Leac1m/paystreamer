# PayStreamer Documentation Site

This application serves the static documentation site for developers looking to integrate the PayStreamer protocol into their Web3 or Web2 applications.

## Overview

The documentation covers:
- High-level protocol concepts (Schedulers, Policies, Platforms)
- Frontend integration utilizing `@paystreamer/sdk`
- Smart contract logic and access control rules
- End-to-end user flows (deposits, subscription creation, automated billing)

## Architecture

* **Framework:** Next.js (App Router)
* **Documentation Generator:** Nextra (Markdown/MDX based)
* **Styling:** Custom CSS tailored to PayStreamer's brand (yellow/black aesthetics)

## Development

```bash
cd apps/docs
pnpm dev
```
